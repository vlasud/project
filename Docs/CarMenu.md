# Меню личного транспорта (`/car`)

`/car` — бизнес-фича (НЕ Core): корень с двумя входами в ЕДИНОЕ меню машины. Код:
`Src/Systems/CarMenuSystem`. Собственного сервиса нет — источник владения —
`PersonalVehicleService`, о машинах — `VehicleService`, парковка у дома —
`ParkedVehicleService`, замок дверей — `VehicleLockService` (`Docs/VehicleLock.md`),
красный чекпоинт-указатель — общий `VehicleWaypointService`.

## Корень `/car`

**LIST-диалог** «Личный транспорт». Кнопки — слева `Выбрать`, справа `Закрыть`
(корень без родителя). Первая строка — превью ДО клика: сидит в своей машине —
её имя, иначе `не за рулем`:

```
Текущая машина - Infernus      <- сидит в своей машине
Мои машины
```
```
Текущая машина - не за рулем   <- не сидит / машина не своя
Мои машины
```

Лейбл — только превью, прав не даёт: гейт всё равно в обработчике клика
(правило видимости). Разделитель — ASCII-дефис ` - ` (не тире, не `~`).

## Вход 1 — «Текущая машина»

**Гейт при выборе пункта**: игрок сидит В СВОЕЙ машине (любое сиденье, не только
водитель) — `CarMenuSystem::ownCurrentVehicle`:

- **личная сессионная** — `VehicleService::getOwner == Owner::Player` И `getOwnerId
  == playerId` (серверный тег, не клиент);
- **ЛИБО припаркованная ИМ** — `VehicleService::getVehicle(playerId)->getID()` есть в
  `ParkedVehicleService::byVehicleId`, и `parked->ownerAccountId == accountId`
  сессии (`PlayerSessionService::getAccountId`).

Расшаренная семье машина ЧУЖОГО владельца (сам игрок — просто член семьи, не
владелец) — **НЕ своя**: сидя в ней, «Текущая машина» откажет. Не в своей машине —
`Вы не в своей машине` (ERROR) + выход, диалог НЕ открывается.

Своя — `currentCarIndex` резолвит индекс записи владения (`owned()`, у
припаркованной live id через parked-запись) и открывает ЕДИНОЕ МЕНЮ МАШИНЫ
(см. ниже) с «Назад» -> корень. Запись владения не нашлась (окно регистрации
после покупки) — тот же отказ `Вы не в своей машине`.

## Раздел 2 — «Мои машины»

**Список** — `DialogStyle_TABLIST_HEADERS` (образец —
`WeaponProficiencySystem::showSkills`, индексация строк без сдвига на шапку —
`FactionSystem::showMembersMenu`): колонки `Машина` / `Где находится`. Пустое
владение -> сообщение в чат, В ДИАЛОГ НЕ ЗАХОДИМ (как раньше):

```
Машина            Где находится      Топливо
Infernus          в гараже           100/100
Sultan            у дома             64/100
Bobcat            Lo_Vlasud[12]      37/100
```

`{имя}` — `VehicleModelNames::displayName(model)` (фолбэк `Модель {id}` для битой
модели). `{где}` — единый словарь `placementStatus` (тот же, что у центральной
парковки): `у дома` (припаркована лично И реально стоит у своей точки — в
пределах `ParkedVehicleService::HOME_SPOT_RADIUS = 30 м` по XY) / `брошена`
(припаркована лично, но пустой экземпляр стоит ДАЛЬШЕ — владелец уехал на ней и
вышел; вернуть на точку — «Респавн»; действует и для расшаренной) /
`у дома семьи` (припаркована и расшарена, стоит у точки — дом лидера семьи) /
`в гараже` (припаркована, но НЕ вызвана — в мире машины нет, подаётся пунктом
«Вызвать машину») / `на парковке` (не припаркована и не в мире — взять на
центральной парковке) / `вызвана` (не припаркована, в мире). Факт «стоит ли у точки» отдаёт
`ParkedVehicleService::isAwayFromSpot` (позиция клиент-авторитетна — влияет
только на слово, прав не даёт).

`{топливо}` — `{остаток}/{FUEL_CAPACITY}` целыми (как индикатор спидометра), по
источнику правды состояния: живой экземпляр -> `VehicleService::getFuel`;
припаркованная без экземпляра («в гараже») -> `Parked::fuel` (персист-снимок); «на парковке»
-> `OwnedVehicle::fuel` (`-1` — не сохранялся, показываем полный бак — столько и
нальёт спавн).

**Оверлей водителя (только в этом списке):** если за рулём живого экземпляра
кто-то сидит (`VehicleService::getDriver != -1`) — колонка показывает КТО вместо
статуса: `{ник}[{playerId}]` (пример: `Lo_Vlasud[12]`). Владельцу важнее «кто
сейчас в моей машине», чем режим размещения; когда водитель выйдет — статус
вернётся. Водитель — серверный источник (`getDriver`), ник строго латиница
(`NicknameService`): без `\t`/`\n`/`{}` — безопасен для tablist-строки, `u()` его
не меняет. Список центральной парковки оверлей НЕ показывает (там выбирают, что
взять, а припаркованные/занятые всё равно не берутся) — базовый словарь общий.
Кнопки: `Выбрать` / `Назад` (-> корень `/car`).

## ЕДИНОЕ МЕНЮ МАШИНЫ (`showCarMenu`, `DialogStyle_LIST`)

ОДИН И ТОТ ЖЕ под-диалог для обоих входов: «Текущая машина» (корень) и выбор
машины из «Мои машины». Заголовок — имя машины. Кнопки: `Выбрать` / `Назад` —
«Назад» ведёт ТУДА, ОТКУДА ПРИШЛИ (`MenuOrigin`: корень либо список «Мои
машины»). Машину идентифицирует ЗАХВАЧЕННЫЙ `carIndex` (индекс `owned()`), НЕ
`listItem` (это выбор ДЕЙСТВИЯ) — ре-валидируется на каждом клике; выбранный
пункт сверяется с пересобранным набором (паттерн прежнего `showCarActions`).

Шесть пунктов — только ДЕЙСТВИЯ над машиной. **УПРАВЛЕНИЯ СОСТОЯНИЕМ МАШИНЫ В
МЕНЮ НЕТ** (три тумблера — двигатель, фары, замок — убраны): двигатель и фары
переключаются КЛАВИШАМИ за рулём (Core `VehicleControlSystem`: левый Ctrl —
двигатель, ЛКМ/левый Alt — фары, см. `Docs/VehicleControls.md`), и диалог их
больше не дублирует. У замка дверей своего входа после удаления пункта НЕ
осталось — `VehicleLockService` жив, но звать его некому (см.
`Docs/VehicleLock.md`).

| Пункт | Лейбл | Гейт/действие |
|---|---|---|
| Вызвать машину | `Вызвать машину` / `Вызвать заново` (машина уже вызвана ЭТИМ игроком — `calledBy == accountId`) | БЕЗ посадки и БЕЗ расстояния -> `ParkedVehicleService::call(dbId, accountId)`; повторный вызов подаёт машину на место (делегат в `respawnHome`) |
| Респавн / Карта / Припарковать / Убрать / Передать-Вернуть | как ниже | серверные гейты действий как ниже |

Отказ «машины нет в мире» остался у «Показать на карте»: `{путь к машине},
чтобы отметить на карте` (`CarMenuSystem::noInstanceHint` — припаркованную у
дома надо вызвать, обычную сессионную взять на парковке).

**Правило видимости**: ВСЕ пункты видны ВСЕГДА — недоступность объясняет
обработчик СООБЩЕНИЕМ при клике, не скрытием пункта. Динамические ЛЕЙБЛЫ
(`Вызвать машину` / `Вызвать заново`, `Передать семье` / `Вернуть от семьи`) —
это НЕ скрытие, это нормально.

1. **`Вызвать машину` / `Вызвать заново`** — подать ПРИПАРКОВАННУЮ машину на её место
   парковки. Ни посадки, ни расстояния: машина появляется на СВОЕЙ точке (у дома), а не
   рядом с игроком, поэтому вызывать можно откуда угодно. Лейбл `Вызвать заново`, если
   `calledBy == accountId` (машина уже в мире по вашему вызову) — и тогда пункт ПОДАЁТ
   её на место заново: `call` делегирует в `respawnHome` (машина не пересоздаётся,
   топливо не обнуляется), а под сидящим водителем отказывает `Occupied` -> `Вы сами за
   рулём — выйдите из машины, чтобы подать её на место` / `Пока в машине водитель,
   подать её на место нельзя`.
   `ParkedVehicleService::call(dbId, accountId)` (accountId СЕРВЕРНЫЙ, из сессии):
   `Ok` -> `Машина вызвана и ждёт на своём месте парковки`; `NotParked` (машина не
   припаркована у дома) -> `Эта машина не в гараже — её сначала нужно припарковать у
   дома`; `NoAccess` -> `Вызывать эту машину может только владелец или семья, которой
   она расшарена`; прочее -> `Сейчас машину вызвать нельзя`. Тексты общие с `/family` ->
   «Транспорт семьи» (`ParkedVehicleCallNotice.h`). **Слот вызова один:** прошлая
   вызванная этим игроком машина уходит из мира сразу, даже если в ней кто-то сидит.
2. **`Респавн`** — убрать/вернуть машину по текущему размещению:
   - **«вызвана»** (сессионная в мире, `vehicleId != -1`, НЕ припаркована) —
     занята водителем (`VehicleService::getDriver != -1`) -> отказ; текст зависит
     от того, КТО за рулём: сам нажавший — `Вы сами за рулём — выйдите из машины,
     чтобы её респавнить` (иначе отказ читался бы как баг «какой водитель, я
     один»), чужой водитель — `Пока в машине водитель, респавн недоступен`;
     иначе `VehicleService::destroy` — экземпляр уходит «на парковку» (владение
     НЕ удаляется, `subscribeDestroyed` обнулит `vehicleId`), игрок вызовет
     машину заново на центральной парковке. `Машина отправлена на парковку.
     Возьмите её там`;
   - **припаркована** («у дома» / «у дома семьи» / «брошена», `parked->vehicleId != -1`) — занята
     водителем (владелец ИЛИ член семьи) -> тот же развод текстов «сам за рулём /
     чужой водитель» (анти-гриф: не выдёргивать машину из-под члена семьи);
     иначе `ParkedVehicleService::
     respawnHome(dbId)` возвращает машину НА ЕЁ ТОЧКУ У ДОМА (spawn-позиция уже =
     точка парковки) через новый `VehicleService::respawn`. **КРИТИЧНО (анти-
     абьюз):** `respawn()` ядра сам даёт ПОЛНЫЙ БАК (`onVehicleRespawn`) —
     `respawnHome` СНАЧАЛА снимает ТЕКУЩИЙ остаток топлива в саму запись
     (`Parked::fuel`), а `ParkedVehicleSystem::onVehicleRespawned` (уже подписан
     на `VehicleService::subscribeRespawned`) восстанавливает его поверх дефолта
     — ТОТ ЖЕ путь, что уже закрывал «бесплатный эвакуатор с заправкой» после
     несанкционированной смерти, БЕЗ дублирования кода (см. `Docs/
     ParkedVehicles.md`, «Персист топлива»). `Машина возвращена на свою точку у
     дома`;
   - **«на парковке»** (записи парковки нет, владение `vehicleId == -1`) — отказ
     `Машина уже на парковке`;
   - **припаркована, но НЕ вызвана** («в гараже», `parked->vehicleId == -1` —
     штатное состояние) — `respawnHome` вернёт `NoInstance` -> `Эта машина в гараже —
     вызовите её, и она приедет на своё место` (возвращать на точку нечего: подача
     машины на место и есть вызов).
3. **`Показать на карте`** — без изменений (см. ниже).
4. **`Припарковать эту машину здесь`** — без изменений логики (см. ниже).
5. **`Убрать с парковки`** — без изменений логики (см. ниже).
6. **`Передать семье` / `Вернуть от семьи`** — динамический лейбл по
   `parkedMode(dbId)`:
   - **не расшарена** (`mode == NOT_PARKED` либо `NO_FAMILY`) -> лейбл `Передать семье` =
     прежняя `shareToFamily` (гейты/тексты БЕЗ изменений: нет семьи -> не владелец
     семьи -> не припаркована -> уже расшарена; уведомление членам семьи);
   - **расшарена** (`mode != NO_FAMILY`) -> лейбл `Вернуть от семьи`: гейт —
     владелец МАШИНЫ (машина всегда личная, шарится только своя припаркованная —
     владельцем СЕМЬИ быть не нужно, чтобы забрать свою же машину). Это ЕДИНСТВЕННЫЙ
     путь снять шеринг — в `/family` -> «Транспорт семьи» выбор строки ВЫЗЫВАЕТ машину
     к её месту парковки, а не забирает её (см. `Docs/ParkedVehicles.md`). `ParkedVehicleService::unshareFromFamily(dbId)`:
     `Ok` -> `Машина возвращена от семьи. Теперь ей пользуетесь только вы` + симметрично
     `shareToFamily` уведомление онлайн-членам семьи (`[{семья}] Семейная машина
     ({имя}) возвращена владельцу`, `{имя}` — `VehicleModelNames::displayName`);
     `NotShared`/`NotParked`/прочее -> `Сейчас нельзя вернуть машину, попробуйте
     позже`.

## Навигация

«Назад» единого меню машины ведёт в ТОЧКУ ВХОДА (`MenuOrigin`): открыто через
«Текущая машина» -> `корень /car`; через список -> `Мои машины` -> `корень /car`
(Назад). Правая кнопка корня — `Закрыть` (родителя нет).

## Действия без изменений (см. `Docs/ParkedVehicles.md` за деталями)

- **Показать на карте** — `liveVehicleId` резолвит live id (у припаркованной —
  через `ParkedVehicleService::byDbId`, у сессионной — из `owned`); `-1` ->
  `{путь к машине}, чтобы отметить на карте` (`noInstanceHint`: `Эта машина в гараже.
  Вызовите её` / `Эта машина на парковке. Возьмите её`);
  иначе `VehicleWaypointService::showFor(player, IVehicle&)` (режим «машина» —
  указатель снимается автоматически при уничтожении экземпляра-цели; см. режим
  «точка» для статических целей вроде входа дома в `Docs/HomeMenu.md`).
- **Припарковать эту машину здесь** / **Убрать с парковки** — предусловия и
  ре-тег НА МЕСТЕ (без destroy/create) — идентичны прежней реализации, код не
  менялся при переработке меню.

## Правило видимости пунктов меню

Пункты диалог-меню (оба раздела) показываем ВСЕМ ВСЕГДА; недоступность (не в
машине / нет семьи / не владелец / не припаркована / занята водителем) —
сообщением при клике, не скрытием. Динамический ЛЕЙБЛ пункта (вызвать/вызвать
заново, передать/вернуть) — не скрытие, это нормально. Гейт — в обработчике, не
в `buildActions`.

| Уведомление членам семьи (возврат) | `INFO_COLOUR` | `[{name}] Семейная машина ({имя}) возвращена владельцу` |

`{имя}` в уведомлениях — `VehicleModelNames::displayName(model)`, как и везде в
`/car` (заголовок под-диалога, список «Мои машины», `/family` → «Транспорт семьи»).

`INFO_COLOUR {120,220,255}`, `ERROR_COLOUR {255,90,90}` — игровые цвета (как в
`ParkingSystem`/`FamilySystem`).

## Регистрация команды

`PlayerCommandService::add("car", {}, …, perm = None, "меню личного транспорта:
текущая машина, парковка, семья, карта", HelpCategory::Misc)`. Без аргументов;
открыта всем; категория «Прочее» (`/help`). Корневой антифлуд команд — в
`PlayerCommandService`.

## Персист

`/car` ничего не хранит между сессиями. Владение — в БД на стороне
`PersonalVehicleService`; парковка — `ParkedVehicleService`.
`VehicleWaypointService` — чисто сессионное состояние. **SQL-миграций нет.**

## Три правила

- **Читер-абуз:** `/car` работает ТОЛЬКО с серверными записями по `playerId`/
  `accountId` сессии; `carIndex` ре-валидируется против актуального `owned()` на
  КАЖДОМ шаге (список -> под-диалог -> действие); `listItem` под-диалога НЕ
  идентифицирует машину (только действие); «Текущая машина» проверяет владение
  СЕРВЕРНО (`ownCurrentVehicle`, ре-валидация на КАЖДОМ клике — диалог мог
  провисеть) — расшаренной семье машиной чужого владельца из своего `/car`
  распорядиться нельзя (хотя сидеть в ней можно — доступ за руль решает отдельный
  `canDrive`). Состоянием машины меню не управляет вовсе (тумблеров нет), так что
  и абьюзить через него двигатель/фары/замок нечем. «Вызвать» и «Респавн» — см.
  `Docs/ParkedVehicles.md` за деталями анти-абьюза (гейт `hasAccess` по серверной
  сессии, снимок топлива перед `respawn`, гейт занятого водителем).
- **Краш/UB:** bounds `playerId` везде; null-гард `IPlayer`/`IVehicle` в колбэках;
  ре-валидация `carIndex`/`listItem`/`ownCurrentVehicle` на каждом клике;
  переоткрытие под-меню «Текущая машина» после действия не рекурсит бесконечно
  (обычный событийный колбэк диалога, не цикл); PER-TICK работы НЕТ.
- **Перф:** построение списков — холодный путь (по команде/клику), O(машин
  игрока); «Текущая машина» — O(1) (одна машина); PER-TICK работы НЕТ.

## Известные шероховатости опыта (геймдизайн, не баг движка)

- **У замка дверей больше нет входа в игре.** Пункт «Закрыть/Открыть двери» убран
  вместе с остальными тумблерами, а другого способа запереть машину игроку не
  дано: `VehicleLockService` продолжает переприменять состояние на стрим-ине, но
  переключить его некому. Пока замок не получит клавишу или команду, фича
  недоступна (см. `Docs/VehicleLock.md`).
