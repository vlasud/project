# Передача денег (/pay)

Код: `Src/Systems/PaymentSystem`.

## Механика

Команда `/pay [id игрока] [сумма]` — передача наличных из рук в руки ближнему
игроку. Оба параметра числовые (`PlayerCommandService::Param::Int`).

Перевод проходит, только если получатель **рядом**: серверная дистанция
плательщик↔получатель ≤ `PAY_RADIUS`, в том же виртуальном мире и интерьере.
Всё считается по серверным позициям (`PlayerLocationService::getPosition` /
`getVirtualWorld` / `getInterior`), не по клиентским.

При успехе:

- баланс плательщика уменьшается на сумму, получателя — увеличивается;
- плательщик проигрывает прерываемую (interruptible) анимацию передачи
  (`DEALER` / `DEALER_DEAL`): из неё можно выйти движением, сервер её не
  переустанавливает;
- обоим участникам в чат уходит строка-уведомление.

## Формат строки уведомления

```
Lo_Vlasud[22] передал Ivan_Ivanov[23] 100$
```

Имена — серверные (`IPlayer::getName()`), id в `[]`, сумма + `$`. Строка
форматируется в стековый буфер через `fmt::format_to_n` (имена и числа — аргументы,
не строка формата).

## Деньги: серверная авторитетность

- Баланс берётся из `PlayerMoneyService::getMoney` (серверный источник правды),
  **не** из клиентского `IPlayer::getMoney`.
- Перевод выполняется абсолютным `PlayerMoneyService::setMoney`: списание у
  плательщика и зачисление получателю — синхронно в одном обработчике, без
  async, поэтому перевод атомарен, HUD обоих участников = новый баланс.
- Потолок баланса — `MONEY_MAX` (`INT_MAX`): клиентский HUD money хранится как
  signed int32, поэтому зачисление выше потолка отвергается.

## Валидации

| Вектор | Проверка |
|----|----|
| Несуществующий/оффлайн получатель | `getPlayers().get(id) != nullptr` |
| Перевод самому себе | `targetId != payerId` |
| Отрицательная/нулевая сумма (кража) | `amount > 0` до каста в `unsigned long long` |
| Перевод больше, чем есть | серверный `payerBalance >= amount` |
| Получатель в другом мире/интерьере | равенство VW и интерьера (серверные) |
| Получатель далеко | `distSq ≤ PAY_RADIUS²` (серверные позиции, без sqrt) |
| Переполнение баланса получателя | `targetBalance + amount ≤ MONEY_MAX` (INT_MAX) |
| Флуд переводами | кулдаун `PAY_COOLDOWN` на игрока между успешными переводами |

## Константы (баланс)

| Имя | Значение | Смысл |
|----|----|----|
| `PAY_RADIUS` | `5.0f` | макс. дистанция передачи из рук в руки |
| `PAY_COLOUR` | `0x33AA33FF` | цвет строки транзакции (зелёный) |
| `PAY_COOLDOWN` | `1000` мс | мин. интервал между успешными переводами на игрока |
| `MONEY_MAX` | `INT_MAX` | потолок баланса (HUD money — signed int32) |
| анимация | `DEALER` / `DEALER_DEAL`, скорость `4.0f`, interruptible | анимация передачи у плательщика |
