# HUD за рулём (спидометр + HP + топливо)

Приборка водителя: скорость (км/ч), HP машины и количество топлива. Три
per-player textdraw, видимы игроку, пока он за рулём (водитель), обновление раз в
0.5 с. Бизнес-фича (не Core).

Код: `Src/Systems/SpeedometerSystem/SpeedometerSystem.{h,cpp}`. Зависимости из
регистра сервисов (core): `TextDrawService`, `PlayerVelocityService`,
`VehicleService`, `TimerService`. Регистрация — `Src/Systems/SystemRegister.cpp`,
после `TextDrawSystem` и рядом с `ServerLogoSystem` (к моменту `initialize()`
сервис textdraw уже получил компонент; остальные сервисы зарегистрированы раньше).

## Механика

- **Только водитель.** HUD появляется на `onPlayerStateChange` с
  `newState == PlayerState_Driver`, скрывается при любом другом стейте. В тике —
  доп. сверка с источником правды `VehicleService::getSeat(id) == 0`; иначе HUD
  гасится. Пассажир и пеший HUD не видят.
- **Три per-player textdraw.** Создаются лениво при первом входе за руль через
  `TextDrawService::createForPlayer(...)` (не глобальные), id запоминаются в
  `Hud` (`speedId`/`hpId`/`fuelId`). Каждый элемент заводится хелпером
  `ensureShown` (создать-если-нет + `show()`). `createForPlayer` НЕ делает
  авто-show — показ/скрытие явно через `IPlayerTextDraw::show()` / `hide()`. Текст
  обновляется `setTextForPlayer` (сервис санитизирует).
- **Скорость — серверная.** `PlayerVelocityService::getSpeed(id)` (м/с, выведена
  из принятых позиций, устойчива к читу), НЕ из сырого `vehicle->getVelocity()`
  (клиентский sync). Водитель движется вместе с машиной, поэтому скорость игрока =
  скорость машины. км/ч = `getSpeed * 3.6`, арифметическое округление до целого
  (`std::lround`). Формат — только число: `fmt::format("{}", speed)`; на
  остановке `0` (прибор присутствует всё время за рулём, как реальная приборка).
- **HP и топливо — из `VehicleService` (источник правды о машине).** Машина
  водителя берётся `getVehicle(id)`, затем по её id:
  - HP: `getHealth(vehicleId)` (серверное HP, не клиентский `vehicle.getHealth()`),
    `lround`, формат `"{}/{}"` со знаменателем `VehicleService::MAX_HEALTH` (= 1000;
    общий источник факта «полное HP», как `FUEL_CAPACITY`).
  - Топливо: `getFuel(vehicleId)`, `lround`, формат `"{}/{}"` со знаменателем
    `lround(VehicleService::FUEL_CAPACITY)` (= 100).
- **Приглушение скорости при заглушённом двигателе.** Число скорости —
  непрозрачный белый (`FFFFFFFF`) при работающем двигателе и alpha `0x50`
  (`FFFFFF50`) при заглушённом (`vehicle->getParams().engine == 0`; `-1`/`1` —
  работает). Цвет переключается через `setColour` + `restream` ТОЛЬКО на смене
  состояния (флаг `Hud::speedDimmed`), не каждый тик. HP и топливо не тускнеют.
- **Обновление — по таймеру 0.5 с**, не per-tick. `TimerService::setInterval(500ms,
  …)` — один глобальный тик на главном потоке; проход `0..MAX_PLAYERS`, тело
  только для активных HUD (`Hud::driving`).
- **Дев-телеметрия ≠ игровой прибор.** `/veldebug`, `/vel` (м/с, десятые) и
  HUD (км/ч целое) намеренно разного формата — их не смешивать.

## Визуальные параметры (макет, применены как есть)

Общие у всех трёх: `alignment = Center`, `style = 3` (шрифт 3),
`textSize = {400.0, 17.0}`, `letterColour = FFFFFFFF` (непрозрачный белый),
`box = false`, `boxColour = 00000080`, `backgroundColour = 000000FF`,
`proportional = true`, `selectable = false`, `shadow = 0`, `outline = 0`.

| Элемент   | position        | letterSize         | текст          |
|-----------|-----------------|--------------------|----------------|
| Скорость  | `{320.0, 392.0}`| `{0.5062, 4.4297}` | `120`          |
| HP        | `{320.0, 430.0}`| `{0.1027, 0.8993}` | `500/1000`     |
| Топливо   | `{320.0, 438.0}`| `{0.1027, 0.8993}` | `50/100`       |

Центр по X = 320 (экран 640), элементы стопкой внизу. Цветовой индикации по
**скорости** (зелёный/жёлтый/красный по порогу) нет — в игре нет ограничения
скорости/штрафов. Единственная динамика цвета — приглушение числа скорости при
заглушённом двигателе (см. ниже).

## Константы баланса

| Константа            | Значение                       | Смысл                       |
|----------------------|--------------------------------|-----------------------------|
| `UPDATE_INTERVAL`    | `500 ms`                       | темп обновления HUD         |
| `MS_TO_KMH`          | `3.6`                          | перевод м/с -> км/ч         |
| `VehicleService::MAX_HEALTH`   | `1000`                | знаменатель индикатора HP   |
| `VehicleService::FUEL_CAPACITY`| `100`                 | знаменатель индикатора бака |

## Три правила

- **Читер-абуз.** Все три значения серверные: скорость —
  `PlayerVelocityService::getSpeed` (из принятых позиций), HP и топливо —
  `VehicleService` (источник правды о машине, не клиентские заявления). HUD
  показывается ТОЛЬКО самому водителю (per-player textdraw) и только при серверном
  стейте водителя (`PlayerState_Driver` + доп. сверка `getSeat == 0` в тике) —
  нельзя навесить чужой HUD или удержать его, выйдя из роли водителя.
- **Краш-безопасность.** `createForPlayer` может вернуть `nullptr` (пул исчерпан)
  — гард на каждый элемент, элемент просто не появляется. `getVehicle` под
  null-проверкой (HP/топливо не обновляются, если машины нет). В `hideFor`/`tick`
  игрок берётся из пула по id с null-проверкой. `playerId` bounds-чекается
  (`0..MAX_PLAYERS`) во всех точках доступа к слоту. Состояние слота сбрасывается
  на `onPlayerConnect` (чистый старт) и `onPlayerDisconnect` (per-player textdraw
  умирает с пулом игрока — destroy не нужен). Таймер не отменяется из своего колбэка.
- **Перф.** Обновление по таймеру 0.5 с, не per-tick. На водителя — O(1) (чтение
  скорости + HP + топлива + три `setTextForPlayer`); тело тика — только для
  активных HUD; без аллокаций на горячем пути кроме форматирования коротких строк.
