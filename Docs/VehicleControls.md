# Управление машиной (билды водителя)

Код: `Src/Systems/Core/VehicleControlSystem`, `Src/Services/Core/VehicleService`
(`setEngine`/`setLights`), `Src/Services/Core/PlayerKeyService` (детекция фронта
клавиш).

## Что делает

Водитель переключает у СВОЕЙ машины:

| Билд | Клавиша (бит) | Действие |
|----|----|----|
| Двигатель вкл/выкл | `Fire` (4) | тоггл `params.engine` через `VehicleService::setEngine` |
| Фары вкл/выкл | `Crouch` (2) | тоггл `params.lights` через `VehicleService::setLights` |

Срабатывает только когда игрок — ВОДИТЕЛЬ (серверный стейт: `getSeat == 0` и
`getVehicle != null`). Пассажир и пеший игрок нажатием ничего не меняют. Чужую
машину тронуть нельзя — гейтинг по серверной правде `VehicleService`.

## Маппинг клавиш

Биты — классические значения SA (`SDK/values.hpp`, `enum Key`; зеркалит
`PlayerKeyService::Key`).

В SA-MP по умолчанию **левый Ctrl и левая кнопка мыши — оба `Fire` (бит 4)**: на
сервер приходит одна битмаска, физические клавиши неразличимы. Развести их
нельзя. Поэтому:

- **двигатель** повешен на `Fire` (4) — это покрывает и левый Ctrl из ТЗ, и ЛКМ
  (оба физических нажатия глушат/заводят двигатель);
- **фары** на тот же `Fire` повесить нельзя (конфликт с двигателем), поэтому
  отведён отдельный свободный бит **`Crouch` (2)**. Это ВЫНУЖДЕННОЕ отклонение от
  «фары на ЛКМ»: ЛКМ серверно неотличима от левого Ctrl. `Crouch` в машине —
  дискретный тап («посмотреть назад»/сабмишн), у подавляющего большинства машин
  без побочного эффекта на езду. При желании заменить на `Submission` (512,
  клаксон) — но тогда переключение фар будет ещё и сигналить.

## Тоггл и трактовка авто-режима (-1)

`params.engine`/`params.lights` имеют три значения: `-1` — клиентский авто-режим,
`0` — выкл, `1` — вкл. Текущее состояние читается из `vehicle.getParams()` и
инвертируется:

- **двигатель**: `-1` (авто) трактуем как «работает» — заведённая машина это
  норма, первое нажатие её глушит (`engine != 0` → считаем включённым);
- **фары**: `-1` (авто) трактуем как «выключены» — первое нажатие включает
  (`lights == 1` → считаем включённым).

## Взаимодействие с «заглохла»

Двигатель переключается через `VehicleService::setEngine`, который НЕ заводит
заглохшую машину (HP добито к порогу пожара — нужен `repair()`). Значит на
заглохшей нажатие «двигатель» не оживит её: тоггл «вкл» уйдёт в `setEngine(on=true)`
и тот выйдет без действия. Заглушить уже заглохшую — без эффекта.

Фары независимы от «заглохла» (`setLights` без ограничения): их можно включать и
на добитой машине.

## Три правила

- **Читер-абуз:** клавишу как клиентский ввод валидировать нельзя, но ДЕЙСТВИЕ
  гейтится серверно — переключаем только двигатель/фары машины, водителем которой
  игрок реально является (`getSeat == 0` + `getVehicle`). Чужую машину не тронуть.
  Спам нажатий отсекает антиспам `PlayerKeyService` (debounce 150 мс).
- **Краш:** не за рулём / нет машины — обработчик выходит (`nullptr`-чек);
  `playerId` валидируется внутри `VehicleService` (границы пула).
- **Перф:** обработчик событийный (фронт клавиши), не per-tick;
  `getParams`/`setParams` — O(1), без аллокаций в горячем пути.
