# Попап названия машины при посадке за руль

При посадке водителя в машину показывается GameText с названием машины
(`VEHICLE_NAME_STYLE`, сейчас стиль `1`). Позиция и шрифт задаются клиентом,
серверу известен только номер стиля. Стиль — из КЛАССИЧЕСКОГО набора SA (0..6),
чтобы рендерилось на всех клиентах, включая легаси 0.3.7; расширенные стили
open.mp (7..15, напр. 7 «SA vehicle names») рисуются только на open.mp-клиенте.
Бизнес-фича (не Core).

Код: `Src/Systems/VehicleNameSystem/VehicleNameSystem.{h,cpp}`. Зависимости из
регистра сервисов (core): `VehicleService`, `GameTextService`. Регистрация —
`Src/Systems/SystemRegister.cpp`, сразу после `VehicleSystem` (bindOccupant уже
проставил водителя на смене стейта — `VehicleService::getVehicle(playerId)`
видит машину).

## Механика

- **Триггер** — `onPlayerStateChange(player, newState, oldState)` с
  `newState == PlayerState_Driver`. Пассажиры (любой другой сид) и прочие смены
  стейта попап не получают и не трогают.
- **Источник имени.** Машина водителя — `VehicleService::getVehicle(playerId)`;
  `nullptr` (рассинхрон стейта — машину уже уничтожили, событие ещё не дошло) —
  ничего не показываем. Имя модели — `VehicleService::getModelName(vehicle->getID())`;
  пустая строка (мусорная/неизвестная модель — на реальной машине водителя
  практически не бывает) — тоже ничего не показываем, лишь бы не рисовать пустой
  попап.
- **Показ.** `GameTextService::show(player, StringView(name.data(), name.size()), 2500ms, 7)`
  — сервис сам санитизирует текст (длина, управляющие символы, парность `~`).
  Имена машин — ASCII (cp1251-идентичны), поэтому показываем `string_view` из
  каталога БЕЗ копии и без `utf8->cp1251` конвертации.
- **Погасание.** Попап гаснет сам по времени (2.5 с) — как и остальные GameText,
  явного `hide()` не требуется. Повторная посадка (в ту же или другую машину)
  просто перепоказывает попап заново на том же слоте стиля 1.

## Константы баланса

| Константа             | Значение | Смысл                                   |
|------------------------|----------|------------------------------------------|
| `SHOW_TIME`            | `2500 ms`| длительность попапа названия машины       |
| `VEHICLE_NAME_STYLE`   | `1`      | стиль GameText (классический SA-набор 0..6 — рендерится на всех клиентах) |

## Три правила

- **Читер-абуз.** GameText — чисто косметика: сообщение сервер -> клиент, никакая
  серверная логика/анти-чит/начисления от него не зависят. Показ завязан на
  серверный факт (`VehicleService::getVehicle` + `getModelName`, не клиентское
  заявление). Многократный вход/выход из машины лишь перепоказывает попап на
  слоте стиля 1 — серверной стоимости кроме самого события смены стейта нет.
- **Краш-безопасность.** `playerId` bounds-чек (`0..MAX_PLAYERS`) перед доступом
  к сервисам. `getVehicle` под null-проверкой (нет машины — просто return).
  `getModelName` возвращает `string_view` на статические данные сервиса — пустая
  строка (не разыменование) для неизвестной модели, тоже гард на `.empty()`.
  Единственная зависимость от источника правды (`VehicleService`), сырой SDK не
  вызывается.
- **Перф.** Событийно (`onPlayerStateChange`), без per-tick тика и таймера. На
  срабатывание — O(1): один `getVehicle`, один `getModelName` (lookup по
  таблице), один `show`. Имя показывается как `string_view` из статического
  каталога — без аллокаций на этом пути (санитизацию в свой буфер делает сервис).
